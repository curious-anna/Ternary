Excel-to-Pseudocode Converter

Enter a single Excel-style formula or shorthand expression. This tool converts it into constrained ternary pseudocode with only allowed operations: ?, :, +, -, *, /, >, <, >=, <=.

Converter rules:

  • Every ternary operator must be complete: (condition) ? value_if_true : value_if_false.
  • No built-in functions in the output; only the permitted expression forms are generated.
  • No new variables can be invented; only input names (normalized to $var) are used.
  • Evaluation is top-down: nested logic is expanded in sequence into nested ternary expressions.

Supports case-insensitive functions: IF, MIN, MAX, AND, OR, ROUND, ROUNDUP, ROUNDDOWN, plus shorthand condition form (condition, trueValue, falseValue?).

Functions (case-insensitive):
  • IF(condition, trueValue, falseValue?) (falseValue defaults to 0)
  • MIN(a,b,...)
  • MAX(a,b,...)
  • AND(a,b,...) -> numeric condition combinator
  • OR(a,b,...) -> numeric condition combinator
  • ROUND(x) (round nearest)
  • ROUNDUP(x) (truncate toward +inf and -inf in numeric style)
  • ROUNDDOWN(x) (truncate toward 0)
Example syntax: (A > 10 || B <= 5, 100, 0) or IF(A > B, MAX(A,B), MIN(A,B))
